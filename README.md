# CMSC408 - Fall 2024 - Homework 7

## Overview

- Homework 6 involves the creation of a Skill Management System using a SQL database to stroe and manage data about people, the skills they have acquired, and the roles they possess. Theres are the relational tables : skills, people, peopleskills, roles, peopleroles 
which track information about people, their skills, roles, when they acquired them and the amount of roles and skilss they have. 

- You will interact with the data base using SQL queries to populate, manipulate,a nd extract relevant data. The project requires constructing tables and retrieving information through quereis.

## PreReqs

To have this up and running you'll need the following:

- VSCode

- Pipx
- Jupyter
- Python/ Python 3

If anything is missing, follow this link for the setup guide: <https://vcu-ssg.github.io/ssg-quarto-python-setup/finalsteps.html>


## Final Touches

Once you've completed everything, just run either:
- poetry run quarto render report.qmd 
- quarto render report.qmd
